# Бинарный формат ArcUXI

`.arcuxi` — AOT-снимок упакованного интерфейса, который читает `arcade.ui::Document`. Версия бинарной структуры на момент v1.9 — **v3**; ранее были несовместимые v1 и v2. Перекомпилируйте исходный HTML/CSS при обновлении формата.

## Структура

Актуальные упаковочные структуры описаны в `tools/arcuxc.py`:

```python
MAGIC  = b'ARCUXI\\x00\\x01'
HEADER = struct.Struct('<8sIIIIIIII32s')
NODE   = struct.Struct('<IIIIIIII')
STYLE  = struct.Struct('<II8fIII4I3fIII')
TRACK  = struct.Struct('<If')
```

Интерфейс упаковывается в little-endian записи и таблицы. `NODE` содержит индексы топологии, стиля, текста и события; `TRACK` кодирует вид Grid-трека и float-значение.

Известные типы треков: `0 = px`, `1 = fr`, `2 = minmax(px, 1fr)`. Поддержка Grid ограничена; запись в бинарном формате не равна полному алгоритму CSS Grid.

## Ограничения

- Бинарник является внутренним форматом проекта, а не публичным стабильным ABI.
- В заголовке есть поле SHA-256, но его проверка загрузчиком не была доказана как обязательная для всех путей.
- Загружать недоверенные `.arcuxi` без дальнейшего аудита границ/размеров и fuzzing не рекомендуется.
- Нельзя считать произвольный файл v1/v2 совместимым с v3.
- Изменения кодировки, alignment и таблиц требуют отдельной ревизии и миграционных тестов.

## Примеры

```bash
python tools/arcuxc.py examples/dashboard.html -o dashboard.arcuxi
./build/debug/arcadeui dashboard.arcuxi --geometry
```

Каноническая спецификация сегодня — **исходный код компилятора и загрузчика**, а не эта обзорная страница. Для tooling опирайтесь на явные размеры/версии и повторно проверяйте формат тестами.
