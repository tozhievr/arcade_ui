# Arcade UI Documentation

Документация экспериментального AOT-движка интерфейсов Arcade UI v1.9.

**Онлайн-версия:** https://tozhievr.github.io/arcade_ui/

## Разделы

1. [Начало работы](guide/getting-started.md) — требования, сборка, запуск, тесты.
2. [Архитектура](guide/architecture.md) — AOT-конвейер, плоское хранение, зависимости, границы.
3. [HTML и CSS](guide/html-css.md) — актуальный поддерживаемый профиль с примерами.
4. [Формат ArcUXI](guide/arcuxi-format.md) — структура, ограничения, совместимость.
5. [C++ API](guide/cpp-api.md) — Document, text modules, callback API.
6. [Текст и Unicode](guide/text-unicode.md) — ICU, bidi, shaping и кэш.
7. [Диагностика](guide/diagnostics.md) — сообщения, JSON и интеграция IDE.
8. [Сборка и CI/CD](guide/build-ci.md) — пресеты, зависимости, GitHub Actions.

[Профиль соответствия стандартам](standards-profile.md) сохранён отдельно. Его ранние подразделы являются историческими заметками и не должны приниматься за подтверждение полной совместимости.

> Проект экспериментальный. Все заявленные возможности следует сверять с тестами и исходниками. HTML Living Standard и CSS Snapshot 2026 поддерживаются **только в документированном подмножестве**.
